# Node Learning Journey

This repository serves as documentation for my coding learning journey. It includes projects and exercises that utilize the following technologies:

- **React.js**: A JavaScript library for building user interfaces.
- **Bootstrap**: A front-end framework for creating responsive and mobile-first web designs.
- **Node.js**: A JavaScript runtime for building scalable and efficient server-side applications.
- **Express**: A minimal and flexible Node.js web application framework.
- **PostgreSQL**: A powerful, open-source relational database system.

The goal of this repository is to track my progress and showcase the skills I acquire while learning these technologies.
